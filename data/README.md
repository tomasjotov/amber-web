# Game data

Original Amiga game data (abandonware), English versions:

- `data/Ambermoon/` — the `Amberfiles` folder of Ambermoon.
- `data/Amberstar/` — the `Amberfiles` folder of Amberstar 1.96, plus `_new/` with the fresh new-game files.

`files.json` in both folders lists the files for static web servers (Apache, nginx, GitHub Pages ...).
Run `node tools/make-file-lists.mjs` again if you change the data.
